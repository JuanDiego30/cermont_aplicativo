# Procedimiento para Consultas y Reclamos de Datos Personales (ARCO / Habeas Data)

## 1. Objetivo

Establecer el procedimiento para que los Titulares de datos personales puedan ejercer sus derechos de Acceso, Consulta, Actualización, Rectificación, Supresión y Revocatoria (ARCO) del tratamiento de sus datos, conforme a la Ley 1581 de 2012.

## 2. Canales de Atención

Los Titulares pueden presentar sus solicitudes a través de los siguientes canales:

| Canal | Medio | Horario |
|-------|-------|---------|
| Plataforma web | Perfil de usuario → "Mis datos y privacidad" | 24/7 |
| Correo electrónico | (pendiente) | Horario laboral |
| Dirección física | (pendiente) | Horario laboral |
| Teléfono | (pendiente) | Horario laboral |

## 3. Tipos de Solicitud

### 3.1 Consulta (Acceso)
El Titular solicita conocer qué datos personales suyos están siendo tratados y cómo.

**Información a entregar:**
- Lista completa de datos personales almacenados.
- Finalidad del tratamiento.
- Origen de los datos.
- Terceros con quienes se han compartido.

### 3.2 Actualización y Rectificación
El Titular solicita corregir datos desactualizados, inexactos o incompletos.

**Documentos requeridos:**
- Identificación oficial.
- Documentos que sustenten la modificación solicitada.

### 3.3 Supresión (Cancelación)
El Titular solicita la eliminación de sus datos personales.

**Procede cuando:**
- Los datos ya no son necesarios para la finalidad.
- Se ha revocado la autorización.
- Los datos fueron obtenidos sin consentimiento.
- Existe orden de autoridad competente.

**No procede cuando:**
- Existe obligación legal de conservarlos.
- Se requiere para defensa judicial.
- Hay relación contractual vigente que los requiera.

### 3.4 Revocatoria
El Titular revoca la autorización otorgada para el tratamiento.

**Efecto:** Cese del tratamiento de datos del Titular a partir de la fecha de revocatoria, sin efecto retroactivo.

## 5. Flujo de Atención

```
1. Recepción
   ├─ El Titular radica la solicitud por cualquier canal.
   └─ Se asigna número de radicado único.

2. Revisión
   ├─ Se verifica identidad del Titular.
   ├─ Se determina tipo de solicitud.
   └─ Se evalúa procedencia.

3. Gestión (si procede)
   ├─ Consulta: Se prepara respuesta con datos solicitados.
   ├─ Rectificación: Se actualizan datos en el sistema.
   └─ Supresión: Se anonimizan o eliminan datos.

4. Respuesta
   └─ Se comunica resultado al Titular por el mismo canal o el indicado.

5. Cierre
   └─ Se registra en auditoría y se archiva.
```

## 6. Seguimiento

El Titular puede consultar el estado de su solicitud en:
- Perfil de usuario → "Mis datos y privacidad" → Historial de solicitudes.
- Correo electrónico: recibirá notificaciones de cambio de estado.

## 7. Quejas ante la SIC

Si el Titular no está satisfecho con la respuesta, puede presentar una queja ante la Superintendencia de Industria y Comercio (SIC), siguiendo el procedimiento establecido en su sitio web oficial.

Permission Hierarchy### Hierarchy RuleThe role hierarchy enforces that **higher-level roles include all permissions of lower-level roles** within the same functional group. Authorization uses two mechanisms:| Mechanism | Function | Logic ||---|---|---|| **Exact role match** | `authorize(...roles)` | User must have one of the listed roles exactly || **Minimum hierarchy level** | `authorizeMinimum(minimumRole)` | User's `ROLE_HIERARCHY[role]` level must be ≤ the minimum role's level || **Owner-or-admin** | `authorizeOwnerOrAdmin(param)` | User must be in `ADMIN_ROLES` or own the resource |### Hierarchy Values```gerente               (0)  ← highest privilegeresidente             (1)coord_administrativo  (2)supervisor            (3)hes                   (4)auxiliar_contable     (5)supervisor_electricista (6)tecnico_electricista  (7)operador              (8)tecnico               (9)auxiliar_hes         (10)oficial_construccion (11)administrativo       (12)pasante              (13)cliente              (14)  ← lowest privilege```### How authorizeMinimum Works```typescript// Example: authorizeMinimum('supervisor') — allows roles with level ≤ 3// Granted: gerente (0), residente (1), coord_administrativo (2), supervisor (3)// Denied: hes (4), auxiliar_contable (5), supervisor_electricista (6), ... cliente (14)```### Implicit Permission InheritanceA role at level N **does not** automatically inherit all permissions of roles at level N+1. Permissions are **explicitly assigned** per role in `ROLE_PERMISSIONS`. Hierarchy is only used by `authorizeMinimum()` for coarse-grained middleware checks.Exception: `ADMIN_ROLES` (gerente, administrativo, coord_administrativo) share user-management and audit access via explicit grouping constants, not hierarchy inheritance.### Typical Minimum-Hierarchy Gates| Gate Level | Roles That Pass | Use Case ||---|---|---|| `gerente` (0) | gerente | System configuration, audit log cleanup || `supervisor` (3) | gerente, residente, coord_adm, supervisor | Order approval, maintenance approval || `hes` (4) | gerente, residente, coord_adm, supervisor, hes | Field operations || `tecnico_electricista` (7) | Levels 0–7 | Resource allocation || `cliente` (14) | All roles | Public/internal gates |---## 5.
